# Pensadores fundacionales de la pedagogía

Recurso educativo interactivo sobre los pensadores fundacionales de la pedagogía. Está construido con HTML, CSS y JavaScript sin dependencias y puede publicarse directamente en GitHub Pages.

## Uso local

Puede abrir `index.html` directamente o servir la carpeta con cualquier servidor estático, por ejemplo:

```powershell
npx serve .
```

## Publicación en GitHub Pages

1. Suba el contenido a la rama principal del repositorio.
2. En GitHub, abra **Settings > Pages**.
3. En **Build and deployment**, seleccione **Deploy from a branch**.
4. Elija la rama principal, carpeta `/ (root)`, y guarde.

Todos los enlaces y recursos usan rutas relativas para funcionar en una URL de proyecto como `https://usuario.github.io/nombre-del-repositorio/`.

## Imágenes

La versión actual usa medallones tipográficos y no requiere imágenes. Consulte `assets/README.md` para incorporar retratos con dimensiones y tratamiento coherentes.
